## 修改与编译

安装 Python 3，以及包含 XeLaTeX 和 ctex 的 MiKTeX 或 TeX Live。当前排版使用 Windows 中文字体。

在 `直线和圆的方程/LaTeX` 目录执行：

```powershell
python compile.py
```

脚本对两份源文件各编译两次，生成 `build/student.pdf` 和 `build/solutions.pdf`。修改题目后请同步核对答案，并检查 PDF 分页与公式显示，再更新交付 PDF 和下载包。

仓库仅收录最新交付版，不包含旧版、编译缓存和检查截图。题目来源见逐题标注。
